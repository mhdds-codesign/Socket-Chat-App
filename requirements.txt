# Socket Chat Application - Requirements

# این پروژه صرفاً از کتابخانه‌های استاندارد و توکار پایتون (Python Standard Library)
# استفاده می‌کند و نیاز به نصب هیچ‌گونه کتابخانهٔ خارجی (Third-Party) از طریق pip ندارد:
#
# - socket        : پیاده‌سازی اتصالات شبکه مبتنی بر پروتکل TCP
# - tkinter       : طراحی و اجرای رابط گرافیکی کاربر (GUI)
# - threading     : مدیریت چندنخی (Multi-threading) برای ارسال و دریافت همزمان
# - _thread       : مدیریت Threadهای کلاینت در سمت سرور
# - os, sys, time : مدیریت فراخوانی‌های سیستمی، فایل‌ها و زمان
# - collections   : ساختار داده‌های کمکی (defaultdict برای مدیریت اتاق‌ها)
#
# ------------------------------------------------------------------------------
# پیش‌نیاز سیستم:
# Python >= 3.8 (تست‌شده روی Python 3.10)
#
# نکته برای سیستم‌عامل‌های لینوکس:
# در توزیع‌های بر پایه دبیان/اوبونتو، پکیج Tkinter ممکن است به‌صورت پیش‌فرض نصب نباشد.
# برای نصب آن دستور زیر را اجرا کنید:
#   sudo apt-get update && sudo apt-get install python3-tk
